# Open VibeKey

[English](README.md) | **简体中文**

让 VibeKey 更适合你的 Mac 使用习惯。

Open VibeKey 是一款免费、开源的 macOS 应用，适用于 Ulanzi AU05 Vibe Key。通过设置窗口和菜单栏面板，自定义旋钮与按键、调整灯光和麦克风设置，并选择 Mac 的音频输入设备。

## 使用要求

- macOS 13 或更新版本。
- 使用设备控制功能需要 Ulanzi AU05 Vibe Key 及其接收器。

## 安装

使用 Homebrew 安装：

```sh
brew install --cask palaemonboy/tap/openvibekey
```

## 如何使用

1. 将接收器连接到 Mac，并打开 VibeKey 的电源。
2. 打开 Open VibeKey，点击菜单栏中的应用图标。
3. 选择「打开设置…」，配置旋钮、按键、灯光和麦克风。
4. 在菜单栏面板中选择输入设备；点击旁边的锁图标，将其锁定为 Mac 的音频输入设备。
5. 如果希望每次登录后都能使用，勾选「开机时启动」。

Open VibeKey 常驻菜单栏，不会显示在 Dock 中。

## 功能

- **自定义快捷键：** 为按钮、旋钮左右转动和旋钮按下分配键盘快捷键或媒体操作。
- **打开应用：** 通过按钮或旋钮按下，启动或切换到指定 App。
- **配置切换：** 保存不同使用场景的配置，并从菜单栏快速切换。
- **旋钮双击切换配置：** 默认开启，在设定时间内连续按两次旋钮，即可循环切换已保存的配置并收到通知，且不会触发单击绑定。单击等待判定时间结束后执行原动作。间隔默认 0.5 秒，通过上下按钮以 0.1 秒调整（范围 0.1–1 秒），自动保存为全局设置，无需逐份配置设置。其他按钮和左右旋转不受影响。需要 App 在后台运行并授予辅助功能权限；关闭主窗口后仍可使用。
- **灯光控制：** 调整全局灯光、亮度，以及工作模式下各个灯的状态。
- **麦克风控制：** 开关设备麦克风、选择降噪等级和调整收音音量。
- **音频输入选择：** 在 VibeKey 麦克风、Mac 内置麦克风及其他可用输入设备之间切换；锁定常用输入设备，避免被意外切换。
- **设备状态：** 查看连接状态、电量和固件信息。
- **开机启动：** 登录 Mac 后即可使用菜单栏控制。

## 使用提示

- 保存到设备的普通键盘快捷键，在退出 Open VibeKey 后仍可使用。「打开 App」功能需要 Open VibeKey 保持运行。
- 「打开 App」的按键绑定可能与其他软件的快捷键冲突。如果没有响应，请检查是否存在快捷键冲突。
- 使用实时输入电平功能时，macOS 可能会请求麦克风权限。
- 控制设备前需要打开 AU05 的电源，仅插入接收器还不够。

## 本机开发测试

首次执行 `bash scripts/setup-dev-signing.sh`，在登录钥匙串中创建固定的本地代码签名身份（可能需要系统授权）。之后执行 `bash scripts/make-app-dev.sh`，生成 `dist/Open VibeKey Dev.app`。开发版使用独立的应用标识和配置存储，不导入历史开发配置，也不会覆盖正式版。它复用本地证书并固定证书与 Bundle ID 的签名要求，无需 Apple ID 或公证，忽略 `SIGN_IDENTITY`；身份缺失时停止构建，不回退到临时签名。不要在每次构建时删除或重建证书。从旧临时签名迁移后，可能需要在隐私设置中删除旧条目并重新添加一次。

测试前请从菜单栏退出正式版，再打开开发版，避免两个版本同时控制设备。开发版仍会修改设备上的实际设置。测试结束后退出开发版，再打开正式版。

双击切换配置默认开启，无需开关；APP 临时接管旋钮按下，原单击设置仍随配置保存。正常退出会恢复设备上的单击设置；如果设备离线导致恢复失败，退出前会提示。强制退出或崩溃无法立即恢复，请重新连接设备并启动 APP。

启动时统一检查辅助功能、麦克风和通知权限；缺少权限时显示检查窗口，各项「设置」按钮可跳转系统设置，只有点击才打开设置或申请权限。状态持续更新，全部通过后才能关闭检查窗口（仍可退出 APP）。本次新授权全部完成后自动打开主页面；仅当前进程权限尚未生效时重启一次，先恢复设备设置，再打开当前版本和主页面。关闭主窗口后，双击监听仍随菜单栏进程运行。切换时先提示「正在切换」，设备写入完成后再确认结果。

实机验收步骤见 [旋钮双击测试](scripts/dial-double-click-testing.md)。
